abstract class A {
    A() {
        show();
    }
    abstract void show();
}
class B extends A {
    int x = 10;
    void show() {
        System.out.println(x);
    }
}

public class Test {
    public static void main(String[] args) {
        B obj = new B();
    }
}

What is the output?

A) 10
B) 0
C) Compilation error
D) Runtime error

Answer: B
